# 错题记录 · 通用分享版

这是一套可在本地使用的错题管理模板：把错题写成 Markdown，借助 AI 规则完成录入、组卷、批改和复习安排。数据保存在自己的电脑上。

## 开始使用

1. 下载或克隆本仓库，用支持 `.cursorrules` 的编辑器打开**仓库根目录**。
2. 在仓库根目录运行 `python3 init_workspace.py`，生成本机专用的空词表、配置和复习看板。重复运行不会覆盖已有内容。
3. 填写生成的 `使用者配置.md` 中的年级和课程范围。只用代称，不写真实姓名；[空白配置模板](templates/使用者配置.md)可供预览。
4. 安装 Python 3.9 或更新版本的依赖：`python3 -m pip install -r requirements.txt`。生成 PDF 还需要 Chrome 或 Chromium；Linux 打印中文时还需安装中文字体。
5. 看 [用户操作手册.md](用户操作手册.md)，把第一道错题录入 `错题记录/01_错题库/`。

想先检查打印是否可用，可运行：

```bash
python3 错题记录/scripts/md_to_exam_pdf.py examples/示例试卷.md
```

生成的 `examples/示例试卷.pdf` 只用于本机检查。[示例错题](examples/示例错题.md)展示录入格式，不会自动进入个人题库。

## 文件怎么分

| 文件或目录 | 用途 |
|:---|:---|
| `.cursorrules`、`错题记录/.cursorrules` | AI 录题、组卷和批改规则 |
| `错题记录/01_错题库/` | 个人错题；分享版为空 |
| `错题记录/02_自定义组卷/` | 试卷模板和打印说明；生成的试卷留在本地 |
| `templates/` | 空白配置、词表和看板；初始化时复制到工作目录 |
| `错题记录/03_英语默写/`、`04_语文默写清单/` | 默写使用说明；词表初始化后生成 |
| `错题记录/05_不熟练知识专区/` | 按知识点整理规则 |
| `错题记录/scripts/` | 抽题、默写、看板和 PDF 脚本 |

**隐私提示：**个人词表、配置、看板、错题、原题照片和试卷默认被 Git 排除。向他人分享自己的修改前，仍请检查提交清单。
