# 智能错题管理系统说明

这套分享版以本地 Markdown 文件保存错题和词表。AI 按根目录 `.cursorrules` 与本目录 `.cursorrules` 协助家长完成录入、组卷、批改；脚本负责抽题、默写卷、看板和 PDF 转换。

## 使用流程

1. 在仓库根目录填写 `使用者配置.md`，打开根目录后让 AI 读取规则。
2. 发送错题照片。AI 先给出题目概括、正确答案、错因和标签，家长核对后再归档到 `01_错题库/`。
3. 说“组数学”或“组英语”。AI 根据 `scripts/pick_exam_weighted.py` 和 `scripts/pick_review_spaced.py` 的结果列确认清单，确认后写 `02_自定义组卷/未完成/exam_*.md`。
4. 在本目录运行 `python3 scripts/md_to_exam_pdf.py "02_自定义组卷/未完成/exam_*.md"` 生成 PDF。
5. 批改后更新错题掌握度和复检日期；完成的试卷移入 `已完成/`。

默写独立使用 `03_英语默写/` 和 `04_语文默写清单/` 的词表；`scripts/build_memo_exam.py` 生成 `memo_*` 卷，`scripts/grade_memo.py` 批改。`scripts/gen_html_hub.py` 可从本地错题生成网页看板。网页、试卷和照片都包含个人学习数据，不要公开上传。

系统细节见 [用户操作手册](../用户操作手册.md)、[目录说明](README.md) 和 [错题整理架构](错题整理架构.md)。
